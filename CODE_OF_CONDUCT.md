# Code of conduct

Solium adopts the **[Contributor Covenant, version
2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** as its
code of conduct. It applies in every project space — issues, pull requests,
discussions, reviews — and when someone represents the project elsewhere.

The full text is at that address and is not copied here. In short: be
respectful, assume good faith, accept criticism of your work gracefully, and do
not harass anyone.

## Reporting

If someone's behaviour breaks the code of conduct, tell the maintainer,
[@IlyaKotomin](https://github.com/IlyaKotomin) on GitHub. For anything you do
not want to say in public, open an issue asking for a private contact, without
details, and the maintainer will reply with one. Reports are handled
confidentially, and the enforcement guidelines in the Covenant are the ones
followed.
